# Ferar Website

A polished marketing landing page for **Ferar**, a fast motorcycle delivery service for everyday city movement.

## Stack

- Vite
- React 19
- Tailwind CSS 4
- ESLint

## Content sections

- Hero with delivery positioning and CTAs
- Problem / solution comparison
- Feature grid
- Four-step delivery flow
- Use cases
- Benefits
- Final CTA and footer

## Run locally

```bash
npm install
npm run dev
```

## Validate / build

```bash
npm run lint
npm run build
npm run preview
```
